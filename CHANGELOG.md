# Changelog

## [0.1.0] — 2026-11-08

First preview.

### Added
- Projects in NakliOS storage, with import and export as zip; writing works on the direct site in browser storage.
- Editor: LaTeX highlighting, completion, linting, list continuation, environment wrap and rename, go to definition, vim and emacs keys, spellcheck through Harper, Format.
- Builds on save through `naklios.experimental_tex`, plain-words errors with one-click fixes, last good PDF kept, PDF find and text selection.
- SyncTeX in both directions, landing on the clicked word.
- Starters: article, slides, thesis, NeurIPS 2026, ICML 2026, ICLR 2026, ACL, CVPR 2027, IEEE.
- Citations: add by arXiv id, DOI or title; OpenAlex discovery; reference audit with Crossref retraction notices; arXiv full text as Markdown; linked `.bib` import.
- Notes and highlights with quote anchors, saved versions, changes PDF, review PDF with annotations.
- AI proofread, polish and revision rounds with protected LaTeX.
- Double-blind check, arXiv pack checked to build alone.
- Git history, three-way merge of outside edits.
- Data sheets, whiteboards saved as figure PDFs, Markdown notes, paragraph preview.
- Experimental: Overleaf sync through Git, agent panel.
